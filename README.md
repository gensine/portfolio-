# Vaishnavi Mishra – AI Engineer Portfolio

A minimalist, high-craft developer portfolio inspired by [chanhdai.com](https://chanhdai.com/) and tailored for an **AI Engineer & Systems Developer**.

## ✨ Features

- **Technical Blueprint Aesthetic**: Fine 1px blueprint borders, lined frame (`max-w-3xl`), diagonal hatch dividers, and obsidian pitch-black palette (`#000000` / `#09090b`).
- **Fig. 1. Latent Tensor Visualizer**: Interactive 3D perspective Neural Synapse Engine that follows cursor coordinates with real-time synaptic data pulses and harmonic Web Audio synth chime.
- **Fig. 2. Activity Matrix**: GitHub contribution heatmap matrix.
- **Featured Projects**:
  1. **IntentGuard** — AI agent payment security with Ed25519 signatures, prompt injection detection, SHA-256 hash-chain, and mock UPI sandbox.
  2. **FreelanceX** — Decentralized freelance marketplace on Base Sepolia with smart contract USDC escrow and 2-of-3 multisig arbitration.
  3. **Unified API Gateway & Health Monitor** — Real-time microservice health, latency analytics, and WebSockets telemetry.
  4. **MerchantAI Catalog Agent** — AI-native catalog ingestion and autonomous commerce agent with ACP/AP2 protocol APIs, money guardrails, and Razorpay test checkout.
  5. **Emoti-Sense AI** — Real-time facial emotion recognition and multilingual sentiment engine.
  6. **Credit Card Fraud Detection** — Imbalanced financial anomaly classification using SMOTE and Random Forest.
  7. **Elyxir** — Relational pharmacy management ERP with 8+ normalized MySQL tables.
  8. **xBridge** — Single-transaction cross-chain swap leveraging LiFi routing on Sepolia.
- **Interactive Command Palette (`⌘K` / `Ctrl+K`)**: Rapid keyboard navigation, section jumps, and quick-copy contact commands.
- **Audio Name Pronunciation**: Synthesized speech button for *"Vaishnavi Mishra"*.
- **Live IST Clock**: Real-time IST clock (`GMT+5:30`) with active availability status dot.

## 🚀 Running Locally

Open `index.html` directly in any modern browser, or run a local server:

```bash
# Python
python -m http.server 3000

# or Node.js npx
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
